# ΣΥΝΟΙΔΑ · site, έκδοση Fable 5.2

Το site των τεσσάρων κέντρων ειδικών θεραπειών ΣΥΝΟΙΔΑ (Αρτέμιδα, Σπάτα, Νέα Μάκρη, Μαραθώνας).
Στατικές σελίδες, χωρίς server και χωρίς εξωτερικές υπηρεσίες. Βάση: η έκδοση Opus 1 (`synoida-site-opus-preview`, commit `b14809f`).

Δοκιμαστική έκδοση: δεν ευρετηριάζεται (noindex) μέχρι να χτιστεί με `--final`.

## Δομή

| Φάκελος | Τι είναι |
|---|---|
| `docs/` | **Ο μόνος φάκελος που δημοσιεύεται.** Παράγεται αυτόματα, δεν τον επεξεργάζεσαι με το χέρι. |
| `_build/template.html` | Κοινό κέλυφος κάθε σελίδας: head, μενού, υποσέλιδο, κάτω μπάρα κινητού. |
| `_build/fragments/` | Το περιεχόμενο (`<main>`) κάθε σελίδας. **Εδώ αλλάζουν τα κείμενα.** |
| `_build/pages.json` | Τίτλος, περιγραφή και όνομα πλοήγησης κάθε σελίδας. |
| `_build/css/` | Τα στυλ σε στρώματα, με αλφαβητική σειρά. Ενώνονται σε ένα αρχείο. |
| `assets/` | Κύριες φωτογραφίες (JPG), λογότυπα, JavaScript, γραμματοσειρές. |
| `_build/tools/` | Εργαλεία που τρέχουν σπάνια: εικόνες, γραμματοσειρές, έλεγχος σε browser. |

Στρώματα CSS: `10-fonts` (παράγεται), `20-utilities` (βοηθητικές κλάσεις), `30-components` (ενότητες και σελίδες),
`40-polish` και `50-system` (ενιαίο σύστημα: αποστάσεις, τίτλοι, κουμπιά, εφέ), `60-page` (βασικοί κανόνες), `70-fable-5.2` (αναγνωσιμότητα και άγγιγμα).
Νέος κανόνας μπαίνει στο τελευταίο στρώμα που ταιριάζει. Δεν ξαναγράφεται κανόνας που υπάρχει ήδη πιο πάνω: αλλάζει εκεί.

## Αλλαγή κειμένου ή σελίδας

```
python3 _build/build.py        # χτίζει το docs/
python3 _build/check.py        # στατικός έλεγχος: πρέπει να γράψει ΟΚ
```

Δεν χρειάζεται κανένα πακέτο, μόνο Python 3.

Προβολή στον υπολογιστή: `python3 -m http.server 8000 --directory docs` και άνοιγμα του http://localhost:8000

## Έλεγχος σε κινητό και υπολογιστή

```
python3 _build/tools/check_browser.py
```

Ανοίγει κάθε σελίδα σε πραγματικό Chrome, σε πλάτος κινητού (390) και υπολογιστή (1440), και ελέγχει: σφάλματα,
οριζόντια κύλιση, αντίθεση κειμένου σε κάθε στάση της κύλισης, μέγεθος κουμπιών για άγγιγμα, βάρος σελίδας, μεγέθη εικόνων.
Χρειάζεται μόνο εγκατεστημένο Google Chrome.

## Νέα ή αλλαγμένη φωτογραφία

Η κύρια φωτογραφία μπαίνει στο `assets/<όνομα>.jpg` (πλάτος 1920) και αναφέρεται στο fragment ως `<img src="assets/<όνομα>.jpg" alt="…">`.

```
python3 -m venv .venv && .venv/bin/pip install pillow        # μία φορά
.venv/bin/python _build/tools/make_images.py                 # εκδόσεις WebP σε 5 πλάτη, στο docs/assets
python3 _build/build.py
python3 _build/tools/measure_sizes.py                        # μετρά πόσο πλάτος πιάνει κάθε εικόνα σε 8 οθόνες
python3 _build/build.py --prune
```

Το `build.py` γράφει μόνο του `srcset`, `sizes`, `width` και `height`. Έτσι κάθε συσκευή κατεβάζει την έκδοση που χρειάζεται.

## Τελική δημοσίευση σε δικό της domain

```
python3 _build/build.py --final --base https://www.synoida.gr/ --prune
python3 _build/check.py
```

Το `--final` βγάζει το σήμα δοκιμής και το noindex, και γράφει robots που επιτρέπει την ευρετηρίαση.
Στον server ανεβαίνει **μόνο** το περιεχόμενο του `docs/`.

## Τι εξασφαλίζει το build

- Ένα αρχείο CSS και μικρά αρχεία JS, με όνομα από το περιεχόμενό τους (αλλάζει μόνο όταν αλλάξουν).
- Γραμματοσειρές τοπικά: 4 αρχεία, περίπου 75 KB συνολικά. Καμία σύνδεση με Google.
- Πολιτική ασφαλείας (CSP): τρέχουν μόνο scripts του ίδιου του site.
- Δομημένα δεδομένα για Google: οργανισμός με τα 4 κέντρα, διαδρομή σελίδας, συχνές ερωτήσεις.
- `sitemap.xml`, `robots.txt`, εικόνα κοινοποίησης 1200x630 ανά σελίδα.

## Κανόνες που ισχύουν

- Τα φόντα και τα χρώματα των ενοτήτων δεν αλλάζουν. Χωρίς λωρίδες 5 χρωμάτων. Το λογότυπο μένει αυθεντικό.
- Στις σελίδες θεραπειών, επίσημο ύφος χωρίς διακοσμητικές μπάλες.
- Χωρίς τιμές. Χωρίς τη λέξη «ερώτημα». Χωρίς μεγάλες παύλες. Τίποτα δεν επινοείται για την επιχείρηση.
- Δημοσίευση μόνο με ρητή εντολή «push».
