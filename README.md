# ΣΥΝΟΙΔΑ · site, έκδοση Fable 5.2

Το site των τεσσάρων κέντρων ειδικών θεραπειών ΣΥΝΟΙΔΑ (Αρτέμιδα, Σπάτα, Νέα Μάκρη, Μαραθώνας).
Στατικές σελίδες, χωρίς server και χωρίς εξωτερικές υπηρεσίες. Βάση: η έκδοση Opus 1 (`synoida-site-opus-preview`, commit `b14809f`).

Δοκιμαστική έκδοση: δεν ευρετηριάζεται (noindex) μέχρι να χτιστεί με `--final`.

## Δομή

| Φάκελος | Τι είναι |
|---|---|
| `docs/` | **Ο μόνος φάκελος που δημοσιεύεται.** Παράγεται αυτόματα, δεν τον επεξεργάζεσαι με το χέρι. |
| `_build/template.html` | Κοινό κέλυφος κάθε σελίδας: head, μενού, υποσέλιδο, κάτω μπάρα κινητού. |
| `_build/fragments/` | Το περιεχόμενο (`<main>`) κάθε σελίδας. **Εδώ αλλάζουν τα κείμενα.** |
| `_build/pages.json` | Τίτλος, περιγραφή και όνομα πλοήγησης κάθε σελίδας. |
| `_build/css/` | Τα στυλ σε στρώματα, με αλφαβητική σειρά. Ενώνονται σε ένα αρχείο. |
| `assets/` | Κύριες φωτογραφίες (JPG), λογότυπα, JavaScript, γραμματοσειρές. |
| `_build/tools/` | Εργαλεία που τρέχουν σπάνια: εικόνες, γραμματοσειρές, έλεγχος σε browser. |

Στρώματα CSS (ενώνονται με αυτή τη σειρά σε ένα αρχείο):

| Αρχείο | Τι έχει |
|---|---|
| `10-fonts` | Γραμματοσειρές. Παράγεται από το `make_fonts.py`. |
| `20-utilities` | Βοηθητικές κλάσεις (αποστάσεις, χρώματα, flex) που χρησιμοποιεί το κέλυφος. |
| `30-components`, `40-polish`, `50-system` | Κεφαλίδα, μενού, τηλέφωνα, υποσέλιδο, λίστα κέντρων, εικονίδια αξιών. |
| `60-page` | Βασικοί κανόνες σελίδας και εμφάνιση στην κύλιση. |
| `70-fable-5.2` | Στόχοι αγγίγματος, σήμα δοκιμαστικής έκδοσης. |
| `80-foundation` | **Το σύστημα:** μεταβλητές (χρώματα, ακτίνες, σκιές, κλίμακα γραμμάτων), κεφαλίδα μίας γραμμής, μεταβάσεις σελίδων. |
| `82-home` | Η Αρχική (κλάσεις `hx-`). |
| `85-inner` | Οι 12 εσωτερικές σελίδες (κλάσεις `pg-`). |

Νέος κανόνας μπαίνει στο `82-home` ή στο `85-inner`. Χρώματα, ακτίνες και μεγέθη γραμμάτων αλλάζουν μόνο στις μεταβλητές του `80-foundation`.
Όταν φύγουν ενότητες ή κλάσεις, το `python3 _build/tools/css_clean.py --apply` σβήνει τους κανόνες που δεν ταιριάζουν πια πουθενά.

Λογότυπα: τα αυθεντικά διανυσματικά αρχεία (`assets/logo-horizontal.svg`, `logo-stacked.svg`, `logo-stacked-light.svg`). Δεν ξανασχεδιάζονται.

## Αλλαγή κειμένου ή σελίδας

```
python3 _build/build.py        # χτίζει το docs/
python3 _build/check.py        # στατικός έλεγχος: πρέπει να γράψει ΟΚ
```

Δεν χρειάζεται κανένα πακέτο, μόνο Python 3.

Προβολή στον υπολογιστή: `python3 -m http.server 8000 --directory docs` και άνοιγμα του http://localhost:8000

## Έλεγχος σε κινητό και υπολογιστή

```
python3 _build/tools/check_browser.py
```

Ανοίγει κάθε σελίδα σε πραγματικό Chrome, σε πλάτος κινητού (390) και υπολογιστή (1440), και ελέγχει: σφάλματα,
οριζόντια κύλιση, αντίθεση κειμένου σε κάθε στάση της κύλισης, μέγεθος κουμπιών για άγγιγμα, βάρος σελίδας, μεγέθη εικόνων.
Χρειάζεται μόνο εγκατεστημένο Google Chrome.

Όταν τρέχει για όλες τις σελίδες δοκιμάζει και: ανοιχτό μενού κινητού σε οθόνες 390x664 και 360x640, λειτουργία χωρίς JavaScript
(και ότι το περιεχόμενο διαβάζεται μετά από κύλιση), αποτυχία φόρτωσης του `site.js`, ότι η σελίδα πίσω από το ανοιχτό μενού δεν
δέχεται εστίαση, τη θέση όπου προσγειώνεται μια άγκυρα, την εκτύπωση (κανένα κείμενο κρυμμένο), αλλαγή πλάτους με ανοιχτό μενού (περιστροφή tablet),
την κεφαλίδα κινητού που κρύβεται και επιστρέφει, ότι η εστίαση μέσα στην κεφαλίδα δεν μετακινεί τη σελίδα,
τον χρόνο εμφάνισης σε αργό κινητό, «μείωση κίνησης», εστίαση πληκτρολογίου, τη σελίδα 404 όπως
τη σερβίρει το GitHub Pages, και βάρος σε κινητό πυκνότητας 3.

**Τι ισχύει χωρίς JavaScript:** όλο το κείμενο φαίνεται, το μενού κινητού είναι ανοιχτό μέσα στη σελίδα (η κεφαλίδα δεν μένει
κολλημένη) και τα τηλέφωνα πατιούνται. Δεν υπάρχουν τα εφέ κύλισης και το κουμπί αντιγραφής email. Το ίδιο ισχύει αν το `site.js`
δεν φορτώσει: το μικρό script στο `<head>` το αντιλαμβάνεται και γυρίζει τη σελίδα στη μορφή χωρίς JavaScript.

**Κεφαλίδα στο κινητό:** κρύβεται όταν κυλάς προς τα κάτω και επιστρέφει όταν κυλάς προς τα πάνω (`site.js`, ενότητα 6β). Δεν
κρύβεται με ανοιχτό μενού, όσο η εστίαση είναι μέσα της, ή για 1,5 δευτερόλεπτο μετά από άφιξη ή άλμα σε άγκυρα.

**Τι ΔΕΝ έχει δοκιμαστεί:** Safari (iPhone, Mac), Firefox και πραγματικές συσκευές. Οι έλεγχοι τρέχουν σε Chrome με προσομοίωση κινητού.
Τα σύγχρονα χαρακτηριστικά CSS (κίνηση δεμένη στην κύλιση, μεταβάσεις σελίδων, `:has()`) έχουν εφεδρεία, αλλά θέλει μια ματιά σε iPhone πριν από τη δημόσια έκδοση.

## Πριν από κάθε push

```
git config core.hooksPath .githooks        # μία φορά ανά υπολογιστή
```

Το `.githooks/pre-push` ξαναχτίζει, τρέχει το `check.py` και σταματά το push αν κάτι αποτύχει ή αν το `docs/` δεν είναι ενημερωμένο (αλλαγμένα ή νέα αρχεία που δεν έχουν μπει σε commit).

## Νέα ή αλλαγμένη φωτογραφία

Η κύρια φωτογραφία μπαίνει στο `assets/<όνομα>.jpg` (πλάτος 1920) και αναφέρεται στο fragment ως `<img src="assets/<όνομα>.jpg" alt="…">`.

```
python3 -m venv .venv && .venv/bin/pip install pillow        # μία φορά
.venv/bin/python _build/tools/make_images.py                 # εκδόσεις WebP σε 6 πλάτη (240 έως 1600), στο docs/assets
python3 _build/build.py
python3 _build/tools/measure_sizes.py                        # μετρά πόσο πλάτος πιάνει κάθε εικόνα σε 8 οθόνες
python3 _build/build.py --prune
```

Το `build.py` γράφει μόνο του `srcset`, `sizes`, `width` και `height`. Έτσι κάθε συσκευή κατεβάζει την έκδοση που χρειάζεται.

## Τελική δημοσίευση σε δικό της domain

Η κατάσταση της έκδοσης ζει στο `_build/site.json` (διεύθυνση, δοκιμαστική ή τελική, έτος υποσέλιδου). Για την τελική, άλλαξε εκεί
`"final": true` και `"base": "https://www.synoida.gr/"` και μετά:

```
python3 _build/build.py --prune
python3 _build/check.py
```

Έτσι και το pre-push hook, που ξαναχτίζει πριν από κάθε push, χτίζει με τις ίδιες ρυθμίσεις και δεν γυρίζει το `docs/` σε δοκιμαστικό.
Τα `--final`, `--preview` και `--base` στη γραμμή εντολών ισχύουν για μία εκτέλεση (π.χ. δοκιμή σε άλλο φάκελο με `--out`).
Το έτος του υποσέλιδου αλλάζει με το χέρι στο `site.json` κάθε Ιανουάριο.
Η τελική έκδοση βγάζει το σήμα δοκιμής και το noindex, και γράφει robots που επιτρέπει την ευρετηρίαση.
Στον server ανεβαίνει **μόνο** το περιεχόμενο του `docs/`.

## Τι εξασφαλίζει το build

- Ένα αρχείο CSS και μικρά αρχεία JS, με όνομα από το περιεχόμενό τους (αλλάζει μόνο όταν αλλάξουν).
- Γραμματοσειρές τοπικά: 4 αρχεία, περίπου 72 KB συνολικά, σε κάθε σελίδα. Καμία σύνδεση με Google. Το `check.py` αποτυγχάνει αν κάποιος χαρακτήρας θα κατέβαζε πέμπτο αρχείο.
- Πολιτική ασφαλείας (CSP): τρέχουν μόνο scripts του ίδιου του site.
- Δομημένα δεδομένα για Google: οργανισμός με τα 4 κέντρα, διαδρομή σελίδας, συχνές ερωτήσεις.
- `sitemap.xml`, `robots.txt`, εικόνα κοινοποίησης 1200x630 ανά σελίδα.

## Κανόνες που ισχύουν

- Δύο ανοιχτά φόντα και ένα σκούρο, από τις μεταβλητές. Το πολύ μία σκούρα ενότητα ανά εσωτερική σελίδα. Χωρίς λωρίδες 5 χρωμάτων. Το λογότυπο μένει αυθεντικό.
- Τολμηρή κίνηση μόνο στην Αρχική. Στις σελίδες θεραπειών, επίσημο ύφος χωρίς διακοσμητικές μπάλες.
- Κανένα κείμενο πάνω σε φωτογραφία. Μόνο πραγματικές φωτογραφίες των χώρων.
- Χωρίς τιμές. Χωρίς τη λέξη «ερώτημα». Χωρίς μεγάλες παύλες. Τίποτα δεν επινοείται για την επιχείρηση.
- Δημοσίευση μόνο με ρητή εντολή «push».
